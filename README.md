# 📦 萬用 PyInstaller 拖曳打包神器

寫好了 Python 腳本，卻總是記不住複雜的 PyInstaller 打包指令？
討厭每次打包完，桌面上都會多出一堆 `build`、`dist` 和 `.spec` 暫存垃圾？

這個「萬用拖曳打包神器」就是為了解放你的雙手而生！

## ✨ 核心特色
* **互動式拖曳**：免改程式碼！直接把 `.py` 檔跟 `.ico` 圖示拖進黑視窗，腳本會自動讀取絕對路徑，徹底解決找不到檔案的報錯。
* **多檔互叫專案**：只要拖「主程式」（你平常 `python xxx.py` 的那個），同資料夾與子資料夾裡互相 `import` 的其它 `.py` 會自動登記進 EXE；也可以直接拖整個專案資料夾（優先找 `main.py` / `app.py`）。
* **智慧判斷**：沒有圖示？直接按 Enter 跳過，腳本會自動切換成無圖示打包模式。
* **🧠 智慧依賴偵測**：不再無腦塞 Selenium！會先掃描專案裡**所有本地 `.py`**（含被主程式呼叫的輔助檔），**只有真的 `import` 到的重量級套件**（如 Selenium、CustomTkinter、Playwright…）才會加 `--collect-all`，別人用不需要的套件就不會被押進 EXE，體積更精簡。
* **GUI / 命令列自動切換**：偵測到 tkinter、PyQt、CustomTkinter 等視窗套件才關黑框 (`-w`)；純命令列腳本則保留 Console，方便看到錯誤訊息。
* **圖示自動無痕轉化**：不用擔心撞名！神器會在背景自動將你的圖示複製並更名為內部核心素材 `app_master_icon.ico`，打包完畢後自動清理，不留任何痕跡。
* **桌面極度潔癖**：自動建立專屬的「打包成品_專案名稱」資料夾，將 EXE 與所有暫存檔集中收納，再也不會弄髒桌面。

## 🚀 使用方法
1. 下載 `一鍵自動打包.bat` 放在任何你喜歡的地方（例如桌面）。
2. 點兩下執行它。
3. 依照畫面指示，將**主程式** `.py` 拖曳進去（多檔專案不要只拖其中一個輔助檔）。也可以直接拖整個專案資料夾。
4. （可選）將你要綁定的 `.ico` 圖示拖曳進去。
5. 喝口水，等它跑完，去新生成的資料夾裡驗收你的 EXE！

打包當下會先印出偵測結果，例如：
```
📄 本地模組：utils
📄 本地模組：helpers.db
✅ 偵測到 GUI 套件 → 使用無黑框模式 (-w)
✅ 偵測到 Selenium （crawler.py）→ 一併打包完整資源 (--collect-all selenium)
📦 已登記 2 個本地模組，會以 hidden-import 一併打進 EXE
```
或：
```
ℹ️  未偵測到 GUI 套件 → 保留命令列視窗
✨ 無需額外重量級資源，將以精簡模式打包
```

## ⚠️ 系統需求
* 請確保你的電腦已經安裝 Python。
* 請確保已經在終端機安裝過打包工具：`pip install pyinstaller`
* 若腳本有用到 Selenium 等套件，請先在本機 `pip install` 過對應套件（打包神器只負責「有用到才收集」，不會幫你安裝）。

### 🎨 關於 EXE 專屬圖示 (.ico) 的使用說明

如果你想讓打包出來的程式，擁有自己專屬的超酷圖示（取代原本醜醜的預設圖），請務必跟著以下步驟做：

**1. 準備正確的 .ico 檔案**
請注意！**不能**直接把 `.png` 或 `.jpg` 重新命名改成 `.ico`，這會導致程式損壞！
* 請先準備一張正方形的圖片（建議 256x256 像素以上的 PNG 檔，支援透明背景）。
* 丟到網路上免費的「PNG 轉 ICO」網站（Google 搜尋即可找到）。
* 將轉換出來的正規 `.ico` 檔案下載下來（**檔名隨便你取，高興就好！**）。

**2. 程式碼的標準化對接**
因為打包神器會**自動**把你的圖示轉化為專屬名稱，所以你完全不用手動改圖示的檔名！
你只需確保你的 Python 程式碼中，是這樣呼叫圖示的即可：
> `window.iconbitmap(get_resource_path("app_master_icon.ico"))`

**3. 一鍵拖曳，無腦打包！**
* 執行 `一鍵自動打包.bat`。
* 第一步：把**主程式** `.py` 拖曳進黑視窗（多檔專案請拖會被直接執行的那一個，或整個資料夾），按 Enter。
* 第二步：把你**任何名字的** `.ico` 檔案拖曳進黑視窗，按 Enter。
* 放開雙手，神器會自動把圖示變成 EXE 的外觀，並完美塞進程式內部供 UI 讀取！
